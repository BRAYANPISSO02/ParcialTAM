Documentación y Fundamentación Teórica del Proyecto

Este sitio interactivo fue diseñado como una herramienta pedagógica rigurosa y autocontenida que materializa las deducciones analíticas de los tres puntos del examen de Aprendizaje de Máquina.

1. Estimación MAP y Penalización Elastic Net

En un modelo de regresión lineal $y = Xw + \epsilon$ con $\epsilon \sim \mathcal{N}(0, \sigma^2 I)$, la log-verosimilitud es cuadrática:

$$\ln p(y|X, w) = -\frac{N}{2}\ln(2\pi\sigma^2) - \frac{1}{2\sigma^2}\|y - Xw\|_2^2$$

Al asumir un prior independiente con densidad de probabilidad combinada (Laplace para esparsidad y Gaussiano para regularización L2):

$$p(w) \propto \exp\left(-\lambda_1 \|w\|_1 - \frac{\lambda_2}{2}\|w\|_2^2\right)$$

El estimador Maximum A Posteriori (MAP) maximiza $\ln p(w|y) = \ln p(y|X,w) + \ln p(w) - \ln p(y)$, lo cual equivale exactamente a:

$$\hat{w}_{MAP} = \arg\min_w \left\{ \frac{1}{2N}\|y - Xw\|_2^2 + \lambda \left[ \alpha \|w\|_1 + \frac{1-\alpha}{2}\|w\|_2^2 \right] \right\}$$

El optimizador implementado en app.js usa Descenso por Coordenadas Cíclico con el operador de umbral suave (Soft-Thresholding):

$$w_j \leftarrow \frac{S\left( \frac{1}{N}X_j^T (y - Xw + X_j w_j),\, \lambda\alpha \right)}{\frac{1}{N}\|X_j\|_2^2 + \lambda(1-\alpha)}$$

2. Análisis Cuadrático Discriminante (QDA) vs Regresión Logística (IRLS)

En QDA, la densidad condicional de cada clase es $x|C_k \sim \mathcal{N}(\mu_k, \Sigma_k)$. La probabilidad posterior $p(C_1|x)$ se obtiene mediante la regla de Bayes:

$$\ln \frac{p(C_1|x)}{p(C_2|x)} = x^T A x + b^T x + c = 0$$

donde la matriz cuadrática $A$, el vector lineal $b$ y la constante $c$ satisfacen:

$$A = -\frac{1}{2}(\Sigma_1^{-1} - \Sigma_2^{-1}), \quad b = \Sigma_1^{-1}\mu_1 - \Sigma_2^{-1}\mu_2$$ $$c = -\frac{1}{2}\mu_1^T \Sigma_1^{-1}\mu_1 + \frac{1}{2}\mu_2^T \Sigma_2^{-1}\mu_2 - \frac{1}{2}\ln\frac{|\Sigma_1|}{|\Sigma_2|} + \ln\frac{\pi_1}{\pi_2}$$

Para Regresión Logística, el modelo discriminativo $p(C_1|x) = \sigma(w^T \phi(x))$ se optimiza con el algoritmo IRLS (Newton-Raphson):

$$w^{(t+1)} = w^{(t)} - \left( \Phi^T W \Phi + \delta I \right)^{-1} \Phi^T (p - t)$$

Al activar la base cuadrática $\phi(x) = [1, x_1, x_2, x_1^2, x_1 x_2, x_2^2]^T$, la frontera de decisión resultante tiene exactamente el mismo grado algebraico que QDA, permitiendo comparar el enfoque generativo y el discriminativo.

3. SVM, Margen Duro y RKHS

El problema dual de la SVM con multiplicadores $\alpha_n$ está dado por:

$$\max_{\alpha} \sum_{n=1}^N \alpha_n - \frac{1}{2}\sum_{n=1}^N \sum_{m=1}^N \alpha_n \alpha_m y_n y_m K(x_n, x_m) \quad \text{s.a.} \quad 0 \le \alpha_n \le C, \; \sum_{n=1}^N \alpha_n y_n = 0$$

Para un clasificador de margen duro con datos separables ($C \to \infty$ o $C$ suficientemente grande), todos los vectores de soporte satisfacen $y_n f(x_n) = 1$. Multiplicando por $\alpha_n$ y sumando sobre todas las muestras:

$$\sum_{n=1}^N \alpha_n y_n f(x_n) = \sum_{n=1}^N \alpha_n \implies \sum_{n=1}^N \alpha_n y_n \left( \sum_{m=1}^N \alpha_m y_m K(x_n, x_m) + b \right) = \sum_{n=1}^N \alpha_n$$

Dado que la restricción dual exige $\sum_{n=1}^N \alpha_n y_n = 0$, el término que acompaña a $b$ se anula idénticamente, demostrando la identidad teórica fundamental:

$$\|w\|_{\mathcal{H}}^2 = \sum_{n=1}^N \sum_{m=1}^N \alpha_n \alpha_m y_n y_m K(x_n, x_m) = \sum_{n=1}^N \alpha_n$$
